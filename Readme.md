# PULSE - Good Health & Well-Being

PULSE is a responsive educational website developed to support **United Nations Sustainable Development Goal 3 (SDG 3): Good Health and Well-Being**. The project aims to raise awareness about health-related topics through interactive features, informative content, and modern web design principles.

## Features

- Interactive Health Profile Management System
- Dynamic Progress Tracking
- Personalized Health Insights
- Healthcare Awareness Content
- Responsive User Interface
- SVG-Based Interactive Sitemap
- User Feedback System
- Health and Well-Being Resources
- Accessibility-Focused Design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- SVG
- Font Awesome

## Project Overview

The website enables users to build a personalized health profile through a multi-step process while exploring content related to healthcare access, healthy lifestyles, and global health initiatives. The project demonstrates modern front-end development techniques including responsive layouts, Flexbox, CSS Grid, DOM manipulation, accessibility features, and interactive user experiences.

## Pages Included

- Home
- Gallery
- Action Impact Simulator (AIS)
- Feedback
- Team
- User Profile
- Sitemap
- Healthcare Content Pages
